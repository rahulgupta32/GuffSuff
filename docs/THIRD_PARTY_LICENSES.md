# GuffSuff Third-Party Open Source License Audit

> **Document Status**: Phase 2 Security Architecture Baseline

---

## License Governance

- All third-party open-source components used in GuffSuff must adhere to permissive open-source licenses (MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, MPL-2.0).
- AGPL-3.0 licensed libraries (e.g. `libsignal`) are under legal evaluation during Phase 2 to determine binary linkage boundaries.
