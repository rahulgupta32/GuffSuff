# GuffSuff Product Roadmap

> **Status**: Initial Draft (Phase 0 Bootstrap)

---

## Phase Breakdown & Milestones

- **Phase 0**: Repository and safety bootstrap (Current)
- **Phase 1**: Product PRD and system architecture specifications
- **Phase 2**: Security foundation, threat model, and privacy architecture
- **Phase 3**: Development platform, CI workflows, and monorepo scaffolding
- **Phase 4**: Identity management, Nepal phone validation (+977), OTP & session security
- **Phase 5**: Core encrypted messaging transport & realtime WebSockets
- **Phase 6**: Integration of approved production E2EE cryptography provider
- **Phase 7**: Group management, attachments, and presigned encrypted media storage
- **Phase 8**: Flutter mobile MVP (Android & iOS) with Nepali Devanagari UI
- **Phase 9**: Administration web console with RBAC & audit logging
- **Phase 10**: Hardening, load testing, SAST/DAST, staging deployment
- **Phase 11**: Final production readiness audit & controlled release
